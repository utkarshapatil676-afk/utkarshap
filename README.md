\# Student Task Manager



A simple web-based Student Task Manager built using Python and Flask.



\## Features



\- Add tasks

\- Edit tasks

\- Delete tasks

\- Mark tasks as completed

\- SQLite database

\- Automated testing with pytest

\- GitHub Actions CI

\- Gunicorn deployment



\## Technologies



\- Python

\- Flask

\- SQLite

\- HTML

\- CSS

\- Pytest

\- GitHub Actions

\- Gunicorn



\## How to Run



Install the dependencies:



pip install -r requirements.txt



Run the application:



python app.py
