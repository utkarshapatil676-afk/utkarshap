\# Student Task Manager



A simple web-based Student Task Manager built using Python and Flask.



\## Features



\- Add new tasks

\- View tasks

\- Edit tasks

\- Delete tasks

\- Mark tasks as completed

\- Store tasks using SQLite

\- Automated testing using pytest

\- Continuous Integration using GitHub Actions

\- Deployment using Gunicorn

\- Health check endpoint



\## Technologies Used



\- Python

\- Flask

\- SQLite

\- HTML

\- CSS

\- Pytest

\- GitHub Actions

\- Gunicorn
